# DE VOLT NIG LIMITED — E-commerce Prototype

A responsive frontend-only fashion e-commerce prototype built with HTML, CSS and vanilla JavaScript.

## Files

- `index.html` — complete storefront markup
- `style.css` — responsive premium fashion styling
- `script.js` — product catalogue, filtering, search, product modal, cart and checkout interactions

## Run

1. Extract/open the folder in VS Code.
2. Open `index.html` in a browser.
3. For the best development experience, use the VS Code Live Server extension.

## Included

- Responsive desktop/tablet/mobile design
- Sticky navigation
- Mobile navigation menu
- Hero section
- Product catalogue
- Category filters
- Product details modal
- Size selection
- Shopping cart
- Quantity controls
- LocalStorage cart persistence
- Search overlay
- Checkout form prototype
- Newsletter interaction
- Toast notifications

## Important

This is a prototype. Products currently use demo image URLs and there is no real payment gateway, database, authentication, order management or backend.

Recommended next phase:
Django + PostgreSQL + admin dashboard + Cloudinary + Paystack/Flutterwave + real product images.
